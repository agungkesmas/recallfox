RecallTape Test Harness

Halaman ini simulasi environment content script RecallTape di halaman web biasa. Klik tombol "Buka RecallTape" untuk menampilkan popover. Lalu test:
  • Ketik 1000 Gaji lalu Enter → harus terformat + 1.000,00 Gaji
  • Ketik + 19% PPN → harus muncul hint | 190,00
  • Ketik = Total → baris subtotal dengan separator + warna emerald
  • Klik 📋 Copy → cek clipboard berisi format plain text
  • Klik 🖨️ Print → harus muncul dialog print (bukan about:blank)
  • Klik 💾 Save → harus muncul log "TAPE_SAVE_TO_VAULT" di bawah
  • Klik 📌 Pin → klik di luar popover → popover tetap terbuka
  • Klik 🗑️ Clear → konfirmasi → editor kosong
